# المنصة العراقية لمعايير الوصول الشامل والتصميم الدامج 🇮🇶
### Iraqi Universal Accessibility & Inclusive Design Platform

> **هذه المنصة قيد التطوير وبمبادرة شخصية من المهندس المعماري الدكتور احمد لؤي احمد.**
>
> **تم تطوير هذه المنصة بالتعاون مع الخبير الدولي في تحوير المباني والمدن لصالح ذوي الاحتياجات الخاصة وكبار السن "المهندس المعماري الدكتور رياض طالب باقر العبيدي".**

---

## 📌 عن المشروع
منصة رقمية وهندسية تفاعلية تهدف إلى تفعيل وتطبيق معايير الوصول الشامل في جمهورية العراق، متوافقة كلياً مع:
* **مدونة متطلبات البناء الخاص بذوي الاحتياجات الخاصة العراقية (`م.ب.ع 202 لسنة 2015`)** المنشورة في جريدة الوقائع العراقية برقم 4396.
* **المعايير الدولية للتصميم المتاح (`ADA Standards for Accessible Design 2010`)** الأمريكية دون أي تعارض، مع تطبيق مبدأ "المعيار الأكثر أماناً وحرية وصول".

---

## 🛠️ المميزات والوحدات الرئيسية للمنصة (8 أقسام كبرى متكاملة)

1. **📊 لوحة المؤشرات الوطنية وخارطة GIS التفاعلية (National GIS Accessibility Map):**
   - خارطة تفاعلية لـ 18 محافظة عراقية (إقليم كردستان، الوسط، الجنوب، والغرب).
   - مؤشرات الامتثال الميداني، عدد الأبنية المعتمدة، المباني قيد التأهيل، وتصدير التقارير الإقليمية الفورية.
2. **🧪 مختبر المحاكاة الفراغية وتصدير مخططات أوتوكاد (Universal Design Lab & CAD/DXF Export):**
   - 7 محاكيات معمارية تفاعلية ثنائية الأبعاد (منحدرات، مرافق صحية، مواقف سيارات، مناورة أبواب، مقصورات مصاعد، خفض أرصفة، ومديات وصول).
   - **تصدير فوري لملفات أوتوكاد التنفيذية (`.DXF`)** لفتحها مباشرة في AutoCAD وRevit.
   - **توليد وتحميل كراسة الشروط والمواصفات الفنية القياسية للمناقصات وعقود المقاولات (Tender Specs)**.
3. **🤖 المدقق الذكي للمخططات المعمارية بالذكاء الاصطناعي (AI Architectural Plan Checker):**
   - فحص وتدقيق المخططات قبل الإنشاء، ورسم التأشيرات الحمراء (Visual Redlines) الآلية على المساقط.
   - فحص الامتثال لبنود `م.ب.ع 202` و `ADA 2010`، وإصدار تقرير المطابقة الهندسية للتراخيص البلدية.
4. **📋 نظام التدقيق الميداني وإصدار الشهادات الذكية (Audit & QR Certification System):**
   - استمارة فحص إلكترونية ذكية بنظام الأوزان المعيارية (ذهبي، فضي، برونزي).
   - توليد شهادة اعتماد وطنية فورية قابلة للطباعة تحمل رمز استجابة سريعة مشفر (Dynamic Vector QR Code).
5. **💰 حاسبة جدول الكميات التخميني والكلفة التقديرية (Retrofit BOQ Calculator):**
   - تخمين كلفة التدخلات المعمارية بالدينار العراقي استناداً إلى أسعار السوق المحلية لعام 2026.
6. **👥 منظومة صوت المواطن والتبليغ عن العوائق (Community Incident & Barrier Reporting):**
   - منصة تشاركية تتيح للمواطنين وذوي الإعاقة التبليغ المباشر عن العوائق الحضرية والمعمارية في المباني العامة.
   - سجل بلدي حي لمتابعة بلاغات التدخل والمعالجة وإشعارات الإنجاز.
7. **🛠️ دليل المعالجات المعمارية وتأهيل الأبنية القائمة (Retrofitting Solutions Guide):**
   - حلول تفصيلية للتعامل مع العوائق الإنشائية المستحيلة، مصاعد الكراسي، المنصات المائلة، والمنحدرات التلسكوبية.
8. **📚 المكتبة والتشريعات الرقمية (Legal & Technical Library):**
   - نصوص مدونة البناء العراقية 202، كود ADA 2010، المذكرات الإلزامية الوزارية، واستمارات التدقيق الميداني.
9. **👁️ محاكي التجربة الحسية والتعايش (Empathy Mode & Sensory Simulator):**
   - فلاتر بصرية فورية تحاكي عمى الألوان (Protanopia / Deuteranopia)، ضبابية الرؤية وضعف البصر لكبار السن (Low Vision)، والرؤية النفقية (Tunnel Vision) لإظهار ضرورة التباين والبلاط اللمسي.

## 🚀 كيفية التشغيل محلياً (Local Setup)

1. استنساخ المستودع:
```bash
git clone https://github.com/<your-username>/iraqi-accessibility-platform.git
cd iraqi-accessibility-platform
```

2. تثبيت الحزم المطلوبة:
```bash
pip install -r requirements.txt
```

3. تشغيل المنصة عبر Streamlit:
```bash
streamlit run app.py
```

## ☁️ النشر السحابي المجاني (Free Cloud Deployment)

### 1. عبر Streamlit Community Cloud (الموصى به)
* ادخل إلى [share.streamlit.io](https://share.streamlit.io) واربط حسابك بـ GitHub.
* اختر هذا المستودع، وحدد ملف `app.py`.
* اضغط **Deploy!** وستحصل على رابط دائم فوري مثل: `https://iraq-accessibility.streamlit.app`.

### 2. عبر GitHub Pages (تشغيل مباشر لملف الـ HTML)
* انسخ ملف `iraqi_accessibility_platform.html` إلى `index.html`.
* في إعدادات المستودع (Settings -> Pages) اختر Branch: `main` و Folder: `/ (root)`.
* سيعمل الموقع مجاناً وفورياً بسرعة فائقة على `https://<your-username>.github.io/<repo-name>`.
